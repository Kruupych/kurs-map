# Курсы рядом

Карта отделений банков Беларуси с курсами обмена: где рядом выгоднее купить или сдать USD, EUR, RUB.

## Запуск

```
npm start
```

Открыть http://localhost:5500. Зависимостей нет, сборки нет. `serve.mjs` раздаёт статические файлы; подойдёт и любой другой статический сервер.

Геолокация в браузере работает только на `localhost` и по HTTPS. Чтобы пользоваться с телефона, папку нужно выложить на статический хостинг с HTTPS.

## Откуда данные

Сервера нет: страница читает myfin.by прямо из браузера (сайт отдаёт `Access-Control-Allow-Origin: *`). Весь разбор разметки лежит в `js/myfin.js`.

| Что | Страница myfin | Когда обновляется |
|---|---|---|
| Список банков города | `/currency/{город}` | раз в 10 минут |
| Курсы и координаты отделений банка | `/bank/{банк}/department/{любое отделение}/courses` | раз в 10 минут |
| Часы работы и телефоны | `/bank/{банк}/otdelenija-spiskom/{город}`, для отсутствующих в списке — страница отделения | раз в 7 дней |

Результаты кэшируются в `localStorage` с префиксом `kurs-map:`. Если myfin поменяет разметку, приложение покажет «на странице города нет отделений с курсами» — править селекторы в `js/myfin.js`.

## Устройство

| Файл | Назначение |
|---|---|
| `js/app.js` | состояние, загрузка, отрисовка списка и меток |
| `js/myfin.js` | загрузка и разбор страниц myfin.by |
| `js/map-view.js` | обёртка над Яндекс Картами (JS API 2.1) |
| `js/templates.js` | HTML списка, сводки и карточки на карте |
| `js/hours.js` | «открыто сейчас» по расписанию, время Минска |
| `js/cities.js` | города myfin и центры крупных городов для автовыбора |
| `js/config.js` | ключ API Яндекс Карт |

Яндекс Карты сейчас загружаются без ключа. Если Яндекс начнёт его требовать, бесплатный ключ «JavaScript API и HTTP Геокодер» из https://developer.tech.yandex.ru вписывается в `js/config.js`.
